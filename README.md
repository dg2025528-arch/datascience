# 지역별 전력 사용량 분석을 통한 태양광 설치 최적화 방안
## 팀원
- 20302 권민솔/ 20327 홍의찬
## 질문
"태양전지는 정말 필요한곳에 잘 설치되어있는가"
## 왜 이 주제인가 
모의고사를 풀다가 태양전지에 대한 문제가 나왔어서 태양전지에 대해 더 공부해보고 싶었고 주제 선정을 할때 태양전지가 가장 먼저 떠올랐다. 또한 태양전지의 활용에 대해 생각하며 정말 필요한곳에 설치되어있는지가 궁금해져서 이 주제를 선정하게 되었다.
